# Rep Tracker — تطبيق تتبع المناديب

تطبيق Expo للمندوب يعمل كحاوية WebView لنظام MASAR، مع حفظ آمن للجلسة وتتبع موقع Native في الخلفية للمندوب والمشرف.

## المتطلبات

- Node.js 18 أو أحدث.
- حساب Expo للوصول إلى خدمة البناء EAS.

## التثبيت والتشغيل المحلي

```bash
cd rep-tracker
npm ci
npx expo start
```

## بناء APK للاختبار

```bash
eas build --platform android --profile preview
```

## بناء APK للإنتاج

```bash
eas build --platform android --profile production
```

## روابط النظام

تُعرّف روابط التطبيق في ملف `App.tsx`:

```ts
const APP_URL = "https://www.masa-erp.com/ar/login";
const API_URL = "https://api.masa-erp.com";
```

## كيف يعمل التطبيق

1. يفتح نظام MASAR في WebView ويعرض صفحة الدخول عند عدم وجود جلسة.
2. بعد تسجيل الدخول، يلتقط التطبيق آخر توكن فعلي من `erp-auth` ويحفظه داخل `SecureStore` في الجهاز.
3. المندوب ينتقل إلى لوحة المندوب، والمشرف إلى لوحة المشرف، وبقية الأدوار إلى لوحة التحكم المناسبة.
4. يتتبع التطبيق موقع المندوب أو المشرف في الخلفية ويرسله إلى API عند تشغيل التتبع.
5. الحساب الأخير يبقى محفوظًا عند إغلاق التطبيق وفتحه.
6. عند الضغط على **تبديل الحساب** من شريط التطبيق، يوقف تتبع الحساب الحالي، ويمسح جلسة WebView والتوكن الآمن، ثم يعيد المستخدم إلى صفحة الدخول.
7. دخول الحساب الجديد يحل محل الحساب السابق؛ لا يعود التطبيق إلى الحساب الأول تلقائيًا.

> لا يستخدم زر تبديل الحساب إلا عند الحاجة للدخول بحساب مختلف. أما إغلاق التطبيق وفتحه فلا يسجل خروجًا تلقائيًا.

## الأذونات المستخدمة

- الموقع أثناء الاستخدام وفي الخلفية: لتتبع المندوب أو المشرف أثناء العمل.
- الإشعارات: لعرض حالة خدمة التتبع على Android.

لا يطلب التطبيق الكاميرا أو الميكروفون عند الإقلاع؛ تُطلب أي صلاحية إضافية فقط عند إضافة ميزة Native تحتاج إليها فعلًا.
