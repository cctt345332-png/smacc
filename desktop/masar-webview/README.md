# Masar ERP Desktop WebView

تطبيق سطح مكتب خفيف يفتح منصة مسار ERP داخل نافذة مستقلة باسم **Masar ERP | مسار**. التطبيق لا ينسخ النظام ولا يخزن بيانات الدخول بنفسه؛ جلسة الموقع وملفات الارتباط تُحفظ في مساحة Electron الدائمة حتى لا يطلب تسجيل الدخول في كل مرة.

## التشغيل المحلي

```bash
cd desktop/masar-webview
npm install
npm start
```

## إنشاء ملف التثبيت

على Linux:

```bash
npm run dist:linux
```

ينتج ملف AppImage داخل مجلد `dist`.

لبناء نسخة Windows من بيئة Windows:

```bash
npm run dist:win
```

ينتج:

- مثبت Windows بصيغة NSIS.
- نسخة Portable بدون تثبيت.

## الاستخدام

يفتح التطبيق مباشرة على:

`https://www.masa-erp.com/ar/landing`

يمكن تسجيل الدخول والتنقل داخل المنصة كالمعتاد. روابط Masar تبقى داخل التطبيق، أما الروابط الخارجية مثل واتساب والبريد فتفتح في المتصفح الافتراضي.

اختصارات المتصفح المعتادة تعمل داخل التطبيق:

- `Alt + Left`: رجوع.
- `Alt + Right`: تقدم.
- `Ctrl + R`: تحديث.
- `Ctrl + L`: التركيز على الصفحة الحالية حسب النظام.

الشعار المرفق مستخدم داخل التطبيق، والأيقونة المربعة مشتقة من علامة Masar للحفاظ على وضوحها في شريط المهام والاختصارات.
