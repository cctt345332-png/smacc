# شجرة الحسابات الافتراضية وربط العمليات المحاسبية

## نطاق الدفعة الأولى

تعتمد هذه الوثيقة شجرة الحسابات ذات **الأكواد الستة** التي قدمها مالك النظام. تُنشأ الشجرة مرة واحدة فقط للشركة التي لا تملك أي حسابات، وجميع أرصدتها الافتتاحية تساوي صفرًا. لا تعدّل هذه الدفعة فاتورة أو عميلًا أو موردًا أو دفعة أو قيدًا أو حركة مخزون قائمة.

> هذه الوثيقة تصميم تشغيلي وتقني. يجب أن يراجع المحاسب المعتمد أسماء الحسابات وتاريخ القطع وسياسات الرسملة والضريبة قبل تفعيل القيود التلقائية للأعمال الحية.

## قواعد الترميز والقيد

| القاعدة | التطبيق |
|---|---|
| صيغة الرمز | ست خانات رقمية، مثل `111001` للصندوق الرئيسي. |
| الحساب التجميعي | لا يقبل القيد المباشر ولا يستخدم في الربط، مثل `111000` النقدية. |
| الحساب النهائي | يقبل القيد ويمكن اختياره في خريطة الربط، مثل `112003` بنك الراجحي. |
| تعدد البنوك أو الفروع | تضاف حسابات نهائية جديدة تحت التجميع المناسب، ثم تربط بالحساب البنكي أو الصندوق المعني. |
| بيانات سابقة | لا يُنشأ لها قيد بأثر رجعي تلقائيًا؛ تعالج لاحقًا بتاريخ قطع ومراجعة صريحة. |

## خريطة الربط الافتراضية

تستخدم الخريطة حسابًا نهائيًا قابلًا للقيد، ويمكن للمدير أو المحاسب تغييره من صفحة دليل الحسابات بعد التهيئة.

| مفتاح العملية | الحساب الافتراضي | ملاحظات |
|---|---:|---|
| الصندوق | `111001` | الصندوق الرئيسي. |
| البنك ومدى والمحفظة | `112001` | حساب تسوية مؤقت إلى أن يربط المدير حسابًا بنكيًا محددًا. |
| ذمم العملاء | `113001` | يستخدم للعملاء بلا حساب فرعي خاص. |
| ذمم الموردين | `211001` | يستخدم للموردين المحليين بلا حساب فرعي خاص. |
| المخزون | `114001` | مخزون البضائع، ثم تخصص فئات الأصناف في الدفعة التالية. |
| ضريبة المدخلات | `115002` | ضريبة المدخلات القابلة للاسترداد على المشتريات والمصروفات المؤهلة. |
| ضريبة المخرجات | `214001` | الضريبة على المبيعات. |
| مبيعات البضائع | `411001` | مبيعات الأجهزة أو الجوالات أو الإكسسوارات تخصص لاحقًا حسب فئة الصنف. |
| مبيعات الخدمات | `412003` | الخدمات الأخرى حتى تخصيص نوع الخدمة. |
| خصم المبيعات | `430000` | حساب مدين لإظهار الخصومات بوضوح. |
| تكلفة البضاعة | `511000` | القيد الافتراضي لتكلفة المخزون المباع. |
| تكلفة الخدمات والمصروف التشغيلي | `584000` | يستخدم مؤقتًا عند عدم وجود تصنيف أدق؛ يراجع المحاسب لاحقًا. |
| فروقات المخزون | `515000` | للعجز أو التلف أو الفروق المعتمدة. |

## الربط بين الأقسام

| العملية عند تفعيلها لاحقًا | القيد المقترح |
|---|---|
| فاتورة بيع آجلة مؤكدة | مدين `113001`، دائن حساب المبيعات المناسب، دائن `214001` للضريبة. |
| فاتورة بيع نقدية | مدين الصندوق أو البنك، دائن حساب المبيعات المناسب، دائن `214001`. |
| بيع صنف مخزني | مدين تكلفة البيع المناسبة، دائن حساب المخزون المناسب بقيمة التكلفة. |
| فاتورة مشتريات مخزنية | مدين المخزون، مدين `115002`، دائن `211001`. |
| فاتورة مصروف | مدين حساب المصروف المختار، مدين `115002`، دائن المورد أو البنك. |
| سند قبض عميل | مدين حساب التحصيل، دائن ذمم العميل. |
| سداد مورد | مدين ذمم المورد، دائن حساب البنك أو الصندوق. |
| مرتجع مبيعات | عكس مبيعات وضريبة وذمم العميل، وعكس تكلفة ومخزون عند استلام الصنف. |
| تسوية مخزون | تستخدم `440004` للزيادة أو `515000` للعجز بعد اعتماد المحاسب. |

## إجراءات الأمان للشركات القائمة

1. تظهر صفحة دليل الحسابات فحص الجاهزية أولًا ولا تُنشئ أي بيانات تلقائيًا.
2. زر التهيئة يعمل فقط إذا كان عدد حسابات الشركة يساوي صفرًا؛ يمنع إنشاء شجرة ثانية فوق حسابات موجودة.
3. التهيئة تضيف الحسابات بأرصدة صفر وتبقي القيود التلقائية متوقفة لهذه الشركة حتى اعتماد المرحلة التالية.
4. زر ربط العملاء والموردين يغير مرجع الذمم لمن لا حساب له فقط؛ ولا ينشئ قيدًا أو يعدل فاتورة أو رصيدًا.
5. بيانات الفواتير والمدفوعات والقيود التاريخية تعرض كمؤشرات مراجعة فقط، ولا يُنشأ لها قيد بأثر رجعي في هذه الدفعة.
6. عند اختيار تاريخ قطع لاحقًا، تكون قيود الافتتاح أو التسوية في معالج مستقل ومعاينة وموافقة صريحة.

## اختبار القبول قبل تفعيل القيود التلقائية

| الاختبار | النتيجة المطلوبة |
|---|---|
| تهيئة شركة بلا حسابات | تنشأ الشجرة الستية والحسابات النهائية وخريطة الربط بأرصدة صفر. |
| تهيئة شركة لديها حسابات | يرفض النظام الإجراء ولا يضيف أو يعدل أي حساب. |
| ربط عميل أو مورد بلا حساب | يتغير مرجع الذمم فقط، من دون قيد أو تغيير في الفاتورة. |
| اختيار حساب تجميعي أو موقوف | يرفضه النظام من خريطة الربط. |
| وجود فواتير أو دفعات سابقة | يبقى العدد والمبلغ والحالة والقيود كما هي. |
| فاتورة جديدة قبل التفعيل | تستمر العملية التشغيلية والمخزون، ولا ينشأ قيد تلقائي قبل اعتماد المرحلة التالية. |

## المرحلة التالية

بعد تهيئة الشركة ومراجعة خريطة الربط، تختبر العمليات الجديدة في بيئة مراقبة: فاتورة بيع آجلة، بيع نقدي، فاتورة مشتريات مخزنية، قبض عميل، سداد مورد ومرتجع. بعدها فقط تربط القيود التلقائية بالخريطة الجديدة وتفعلها صراحة للشركة.
